# Smart Desktop Automation System

## 1. Project Overview
The Smart Desktop Automation System is a Python application designed to automate repetitive computer tasks through a simple menu-driven interface.

## 2. Objectives
- Automate basic desktop operations.
- Create folders automatically.
- Organize files by extension.
- Capture desktop screenshots.
- Generate text files.
- Open websites automatically.

## 3. Technologies Used
- Python
- PyAutoGUI
- pathlib
- os
- shutil
- webbrowser
- datetime

## 4. Features
1. Open Google or YouTube.
2. Create a new folder.
3. Organize files by extension.
4. Take a desktop screenshot.
5. Create a text file.
6. Exit the application.

## 5. Installation
Install the required dependency:

pip install -r requirements.txt

## 6. How to Run
Execute the following command:

python automation.py

## 7. How It Works
The application displays a menu of automation tasks. The user selects an option, provides the required information, and the program performs the corresponding operation.

## 8. File Organization
The application groups files into folders according to their extensions. For example, TXT files are moved into TXT_Files and PDF files into PDF_Files.

## 9. Screenshot Functionality
The program captures the current desktop screen and saves the image as a PNG file.

## 10. Conclusion
This project demonstrates how Python can automate repetitive computer tasks, improve efficiency, and simplify basic desktop operations.
